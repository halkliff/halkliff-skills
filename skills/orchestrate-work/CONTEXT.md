# Terms that affect decisions

- **Local acceptance:** Sol has reviewed a result against the task criteria.
- **Delivery:** Accepted source changes have reached the author's checkout,
  uncommitted. This alone does not establish integrated behavior.
- **Root acceptance:** Astra has verified relevant integrated criteria. The accepted
  checkpoint can serve as a workstream prerequisite.
- **Dependency hold:** A scoped stop awaiting a decision, valid input or correction.
- **Goal pause:** An author-requested stop of all goal work, including independent
  assignments; subject to the host's lifecycle operations.
- **Established independence:** None of an unresolved decision's alternatives
  affects the assignment's inputs, behavior or shared resources.
- **Bounded internal discretion:** Authority to choose and verify reversible internal
  details inside accepted requirements.
- **Workstream clone:** Agent-owned repository with separate refs for implementation.
- **Integration clone:** Astra-owned committed integration history, from which
  accepted slices are delivered and other workstreams synchronize.
